# Changelog

## [1.5.7] - 2026-11-10

### 추가
- **계정의 모든 채널 수집** (`scan_all_channels`, 기본 켜짐): 한 구글 계정의 본채널과 브랜드 채널 시청 기록·구독을 구분 없이 합쳐서 수집
  - 쿠키를 내보낼 때 어떤 채널이 선택돼 있었는지와 무관하게 모든 채널을 조회 (YouTube 내부 API `browse` + 채널별 `onBehalfOfUser`)
  - 채널마다 가장 최근 영상을 각각 기록, 구독은 모든 채널의 합집합
  - 채널 구성이 바뀌면(채널 추가 등) 구독을 신규/취소로 잘못 기록하지 않도록 비교 기준만 새로 잡음
  - 일부 채널 조회 실패 시 이전 구독 목록 유지, 전체 실패 시 기존 방식(선택된 채널)으로 동작

## [1.5.6] - 2026-11-10

### 보안
- **저장형 XSS 수정**: 인증 없는 `POST /api/ingest`로 들어온 url/썸네일/재생시간이 웹 UI에 이스케이프 없이 들어가던 문제 (HA Ingress와 같은 출처에서 스크립트 실행 가능)
  - 서버: video_id 형식 검증, url·썸네일은 video_id로 직접 생성, 제목·채널 300자 제한, 재생시간 형식 검증, 본문 64KB 제한, JSON 객체가 아니면 400
  - 웹 UI: 모든 속성 값 이스케이프(따옴표 포함), 링크·이미지는 http(s)만 허용, 외부 링크 `rel="noopener noreferrer"`
- HTTP 연결 소켓 타임아웃 30초 (멈춘 연결 하나가 단일 스레드 서버 전체를 막지 않도록)

### 수정
- `/api/ingest`에 잘못된 Content-Length나 객체가 아닌 JSON이 오면 예외가 나던 문제
- 구독 오기록 복구를 설치당 1회만 실행하도록 변경 (이후 재시작 때 기존 데이터를 건드리지 않음)

## [1.5.5] - 2026-11-10

### 수정
- **구독 채널 목록이 일부(4개)만 조회되던 회귀**: 1.5.4에서 바뀐 요청 헤더(User-Agent, Sec-Fetch-Mode 등)를 1.4.x와 동일하게 원복 (가장 유력한 원인)
- 위 회귀로 생긴 **대량 '구독 취소' 오기록 자동 복구** (시작 시 한 달 100건 이상이면 오기록으로 보고 기준 목록 복원)
- 로그아웃 응답의 로그인 쿠키 삭제 요청을 막을 때 파일 전체를 다시 읽던 방식 → 지워진 로그인 쿠키만 되돌리고 다른 갱신 쿠키는 저장, 같은 경고는 한 번만 기록
- 쿠키 업데이트 대기 문구 "최대 20초" → "최대 1분" (실제 검증에 약 40초 소요)

### 추가
- 구독 목록이 한 번에 절반 이상(20개 이상) 빠지면 기록하지 않음. 같은 목록이 24시간 유지될 때만 기록 없이 기준 목록 교체
- 구독 채널 수가 바뀔 때 진단 로그 (`[구독] 채널 N개 조회 ...`)
- 쿠키가 다시 유효해지면 구독·추천 영상을 다음 주기에 바로 다시 조회 (추천 센서가 30분간 비어 있던 문제)

## [1.5.4] - 2026-11-10

### 추가
- **쿠키 자동 갱신**: YouTube/Google이 보내 주는 새 쿠키를 파일에 자동 저장하고, 약 10분마다 Google 쿠키 회전(RotateCookies)으로 로그인 세션 유지
- 쿠키 만료 감지(`LOGGED_IN` 값) 시 자동 복구 시도, 실패하면 HA 알림 표시 (`notify_cookie_invalid`, 정상화되면 자동 제거)
- 웹 UI **쿠키 업데이트** 버튼: cookies.txt 파일 선택/붙여넣기 → 저장 후 즉시 로그인 확인 (기존 파일은 `.bak` 보관)
- `POST /api/cookies` (Ingress 경유만 허용), `/api/health`에 `cookie_problem`, `cookie_maintenance` 추가
- 쿠키 기능 단위 테스트 (`tests/`)

### 변경
- 쿠키 파일을 매번 새로 읽지 않고 하나의 세션을 유지. 파일이 바깥에서 바뀌면 자동으로 다시 읽음
- 로그아웃 응답 시 구독 채널 목록을 비우지 않고 직전 데이터 유지
- `homeassistant_api: true` (HA 알림용)

## [1.5.1] - 2026-05-02

### MQTT 최근 시청 영상 센서 추가
- `sensor.youtube_recent_watched`
  - state: 가장 최근 시청한 영상 제목
  - attributes: video_id / channel / url / thumbnail / duration / observed_at
  - attributes.recent_videos: 최근 5개 영상 리스트 (자동화·카드 활용)
- 새 영상 시청 감지 시 즉시 MQTT 발행 (state_changed 트리거 가능)
- 시작 시점에도 1회 발행

## [1.5.0] - 2026-05-02

### 쿠키 상태 검출 로직 개선
- YouTube ytcfg의 `LOGGED_IN` 마커를 매 응답마다 직접 검사
- 쿠키 만료 시 즉시 `cookies_valid=False` 반영 (이전엔 한번 True가 되면 영원히 True)
- 만료 감지 시 경고 로그 추가

### MQTT Home Assistant Discovery 추가
- HA에 자동 등록되는 sensor: `youtube_recommended_1/2/3` (제목 + 영상 정보 attributes)
- `binary_sensor.youtube_cookies_valid` (connectivity, LWT 적용)
- `sensor.youtube_recommended_count` (추천 영상 개수, 자동화 트리거용)
- HA Supervisor에서 MQTT 정보 자동 조회 (`services: ["mqtt:want"]`)
- HA에 MQTT 통합이 없으면 자동으로 건너뜀 (선택사항)
